# Microsoft Sentinel SOC Lab

## Overview

A practical cybersecurity laboratory demonstrating Security Operations Centre (SOC) activities using Microsoft Sentinel, KQL, Microsoft Entra ID and Microsoft security technologies.

The project focuses on security monitoring, detection engineering, identity threat detection, incident investigation and response.

## Objectives

- Develop security detections using KQL
- Investigate suspicious authentication activity
- Analyse Microsoft Entra ID sign-in events
- Identify potential account compromise
- Document incident response procedures
- Develop practical SOC investigation skills

## Technologies

- Microsoft Sentinel
- Kusto Query Language (KQL)
- Microsoft Entra ID
- Microsoft Defender
- Microsoft 365
- Azure
