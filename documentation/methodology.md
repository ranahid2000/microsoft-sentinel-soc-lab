# SOC Investigation Methodology

## 1. Alert Validation

Determine whether the alert contains sufficient information for investigation.

## 2. User Validation

Identify the affected account and determine whether the activity is expected.

## 3. Authentication Analysis

Review:

- Source IP
- Geographic location
- Device
- Application
- Authentication method
- MFA status
- Sign-in result

## 4. Threat Assessment

Determine whether the activity could indicate:

- Credential compromise
- Account takeover
- Password spraying
- Unauthorised access
- Legitimate travel or VPN usage

## 5. Containment

Where compromise is suspected:

- Revoke sessions
- Reset credentials
- Review MFA
- Block malicious indicators where appropriate

## 6. Recovery

Restore normal access after confirming the account is secure.

## 7. Documentation

Record findings, evidence, actions taken and recommendations.
